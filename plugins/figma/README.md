# figma

Skills for working in a design file: a radiograph from a photo, motion
gaps, a camera move, an interface craft pass, component handoff, color
tokens, a component audit, the missing UI states, a design review, and a
usability-test guide.

## Install

```
/plugin marketplace add mind-code-ai/mindcode-plugins-official
/plugin install figma@mindcode-plugins-official
```

## Skills

| Skill | Use it for |
| --- | --- |
| `/figma:xray-scan` | A monochrome radiograph of a photo or a described object, in two finishes |
| `/figma:find-animation-opportunities` | Where a frame should move, and where it should stay still |
| `/figma:camera-pan-and-zoom` | A pan, zoom, or roll that leaves the design frames alone |
| `/figma:better-interface` | Type, layout, accessibility, motion, and the words on the screen |
| `/figma:component-handoff` | An editable documentation frame for one component |
| `/figma:create-color` | Fills, strokes, and shadows mapped to tokens |
| `/figma:analyze-components` | Orphans, duplicates, and names, fixed in one pass |
| `/figma:ui-state-expander` | Loading, empty, error, disabled, partial, and edge states |
| `/figma:design-review` | A critique sorted into blockers, fixes, and what already works |
| `/figma:usability-test-guide` | Moderation questions beside each frame in a flow |
