# Component handoff

Select one component or one component set. Build a single editable frame. Use live instances, not a flattened picture.

Include:

- A header with the name, version, owner, and a one-line description.
- A live preview.
- A grid of the variants.
- A do and a don't, each with an instance.
- States, and the trigger for each one.
- Anatomy, with every part named.

Keep the frame editable in the file so the next person can retarget it at another component.
