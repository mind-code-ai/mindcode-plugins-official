# Design review

Read the file against five questions:

- Can someone complete the job?
- Can they perceive and operate every control?
- Does the eye land on the primary action?
- Do interactions explain what changed?
- Does the screen serve the product goal, or only look finished?

Sort every note:

- Blocker. Shipping this breaks the job.
- Fix. Change it before the next review.
- Keep. This already works.

Each note names the frame, the problem, and the change. Lead with blockers.
