# Radiograph

Work on the selected image, or on the object the user described. Put the results on the canvas beside the source.

Produce two finishes:

- Glowing white structure on black.
- Soft dark tones on white.

Keep both monochrome, with a bright edge, so later layers can stack. Draw the inside of the object, the parts a photograph hides: frame, wiring, joints, cavities. Match the outer silhouette of the source.

Leave color, captions, and labels off unless the user asks for them.
