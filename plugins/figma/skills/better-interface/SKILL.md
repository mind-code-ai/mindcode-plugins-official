# Interface craft

Read the selection and fix what fails. Report each change on the canvas.

- Type uses one scale. Weights stay consistent. Lines stay short enough to read.
- Layout sits on one grid. Spacing comes from one scale.
- Contrast, hit targets, and focus are explicit. Meaning is readable without color alone.
- Motion explains a change. Decorative motion comes off.
- Labels name the action. An error says what to do next.

Change the file. A note that only describes the problem is unfinished.
