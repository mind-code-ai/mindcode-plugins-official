# Motion gaps

Read one frame. If the user has not said who the screen is for, ask before proposing motion.

For each suggestion name the element, the motion, and the values: duration, easing, delay, and distance or scale. Separate two lists:

- Add motion where a change would otherwise be invisible: a panel opening, a selection moving, content arriving.
- Remove motion that decorates without explaining a change.

Point the notes at the frame. Apply the motion only when the user asks.
