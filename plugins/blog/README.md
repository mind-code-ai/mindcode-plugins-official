# blog

Writes and edits engineering blog posts. The opening states the problem
or the result, the middle explains the system and the trade-off, and the
close gives the reader a next step.

## Install

```
/plugin marketplace add mind-code-ai/mindcode-plugins-official
/plugin install blog@mindcode-plugins-official
```

## Skills

| Skill | Use it for |
| --- | --- |
| `/blog:blog-writing` | A new post, or a pass on a draft: launch notes, postmortems, tutorials, and engineering deep dives |
